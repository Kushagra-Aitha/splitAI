The trained model is derived in part from:

Almeida, T. & Hidalgo, J. (2011). **SMS Spam Collection** [Dataset].
UCI Machine Learning Repository. DOI: [10.24432/C5CC84](https://doi.org/10.24432/C5CC84).

Source and license: [UCI dataset page](https://archive.ics.uci.edu/dataset/228/sms+spam+collection),
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

Changes: contact/URL/numeric identifiers normalized; messages deduplicated;
token and bigram weights trained with synthetic Split examples. Raw SMS
messages are not redistributed in the repository. The authors do not
endorse Split or this classifier. Evaluation limitations are in README.md.
